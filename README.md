# 🎰 NEON CASINO — топовый бот + мини-апп (без реальных денег!)

Всё виртуальное: фармишь тапами 👆 → ставишь в казино 🎲 → открываешь кейсы 📦 → бьёшься в PvP ⚔️

## Что внутри
- **Тапалка**: безлимитная энергия ∞, 0.5 монеты/тап, 10% шанс x5, 1% шанс x20 (~500-600 за 5 мин активного тапа — на первый деп). После 1000 тапов/день награда режется (анти-зажор, но лудомания остаётся 😈)
- **Соло-игры (6)**: 🎰 слоты, 🎲 дайс (кнопки 25%/50%/75% + 2x/4x как в CaseBattle), 🎡 рулетка, 💣 мины 5x5, 🚀 краш, 🃏 блекджек
- **Кейсы как в CaseBattle**: СТАРТ/NEON/WHALE, анимация ленты, инвентарь, продажа, вывод «как подарок TG»
- **Депозит подарками TG** (виртуально): 🌹🎂🚀💍 → монеты
- **Онлайн-максимум**: PvP-дуэли (монетка/дайс/КНБ) с комиссией 5%, 🏆 рейтинг, live-лента ставок, 💬 чат
- **Админка**: `/give <id> <сумма>`, `/take`, `/stats` в боте + панель в мини-аппе (вкладка Профиль)
- **Дизайн живой**: неон, парящие монеты, дождь из монет, комбо-бар, конфетти, анимации каждого выигрыша

## Папка
`Рабочий стол/казино/` — `bot.py` (точка входа) + `backend/` + `bot/` + `frontend/` + этот README

## Запуск за 5 минут
1. **Поставь Python 3.10+** (галочка ADD TO PATH)
2. **Создай бота**: напиши @BotFather → /newbot → скопируй токен
3. Открой папку `казино`, скопируй `.env.example` → `.env`, вставь `BOT_TOKEN=...`
4. Запусти **`запуск.bat`** (один процесс: сайт на :5005 + бот)
5. Проверь в браузере: http://localhost:5005/ — тапалка и игры работают
6. **Чтобы открывалось в Telegram**:
   - `ngrok http 8000` → получишь `https://xxx.ngrok-free.app`
   - в `.env` поставь `WEBAPP_URL=https://xxx.ngrok-free.app/`, перезапусти `запуск.bat`
   - @BotFather → /setmenubutton → выбери бота → вставь URL
   - напиши боту /start → жми «🎰 ОТКРЫТЬ КАЗИНО»

## Экономика (чтобы не зажрались)
- Старт: 1000 монет, дейли 500, тапалка 0.5/тап с критами
- RTP игр ~95%: казино медленно жрёт банк → хочется дофармить тапами → лудомания ♻️
- Комиссия PvP 5% сжигается

## Деплой на Bothost (лёгкий режим)
- **Точка входа:** корневой `bot.py` — автоопределение Bothost находит его само. Поле «Главный файл» можно не трогать
- **Галочка «Использовать собственный Dockerfile»** — включи, так надёжнее (Dockerfile уже в корне, `CMD` стартует тот же `bot.py`)
- **Порт:** **5005** (дефолт в коде; если хост даёт свой через `PORT` — подхватится сам). Внутренний порт в панели = тому же числу
- Включи опцию **«Использовать домен»**
- В панели бота всё решается через панель, файл `.env` туда даже не копируется специально
